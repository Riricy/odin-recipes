# FBA 飞书协作版（3～5 人）

**第一次使用，请只看：`开始使用_超简版教程.md`。**

这个项目会把 HTML 网页上的 SKU、库存、日销和补货批次保存到飞书多维表格，供 3～5 人通过同一个网站协作。免费额度优化版默认服务器每 20 分钟检查一次飞书变动；其他同事在网页上填写的数据一般约 8 秒内出现在你的页面。

**重要：** 本 ZIP 还不是在线网址。管理员需要完成教程里的飞书授权和网站部署。不要把 `.env` 上传到 GitHub，也不要对已有飞书数据重复运行 `npm run seed`。

只有报错或需要升级时，再阅读 `进阶说明_需要排错时再看.md`、`升级须知.txt`。

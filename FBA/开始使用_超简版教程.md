# 飞书 FBA 多人协作：照着做就行

**最后效果：** 你和 3～5 位同事打开**同一个网页链接**，添加 SKU、修改库存，其他人也能看到。你只需要安装和配置一次，同事无需安装软件。

> 提醒：下载的 HTML/ZIP **还不是在线网站**。第一次必须连接飞书，并把网页发布到网上。**不需要购买飞书会员**；网页托管是否收费，要以你选的平台为准。

## 第一步：在飞书准备数据表（约定好名字即可）

1. 打开飞书 → **新建 → 多维表格** → 名字填 `FBA库存协作`。
2. 打开 [飞书开放平台](https://open.feishu.cn/app/) → **创建企业自建应用**。
3. 在应用后台找到并复制 **App ID**、**App Secret**；开通**多维表格的读取、编辑、创建表及字段相关权限**，按提示发布应用。
4. 在刚创建的多维表格里，授权这个应用访问。
5. 从表格原始网址的 `/base/` 后复制一串字符，记为 **App Token**。

**到这里，你手里应该有 3 样东西：App ID、App Secret、App Token。**

## 第二步：在自己的电脑启动网页

1. 下载并解压项目 ZIP；安装 [Node.js（LTS）](https://nodejs.org/)。
2. 在项目文件夹中，将 `.env.example` 复制一份，改名为 `.env`（注意文件名最前面有一个点）。
3. 用记事本打开 `.env`，只改下面 **4 行**，其他内容不动：

```ini
FEISHU_APP_ID=填你的AppID
FEISHU_APP_SECRET=填你的AppSecret
FEISHU_APP_TOKEN=填你的AppToken
TEAM_PASSWORD=自己设一个至少16位的团队登录口令
```

4. 在 **Windows 文件夹地址栏输入 `cmd`** 并回车，在弹出的黑色窗口中逐行输入：

```bash
npm run setup
npm run seed
npm start
```

打开浏览器访问 **http://localhost:3000**，输入团队登录口令。能看到原来的 FBA 页面就是启动成功。

**注意：** `npm run seed` **只在第一次建空表时运行一次**！如果飞书表格里已经有数据，别再运行它。

## 第三步：让同事也能打开（发布网址）

1. 把解压后的**项目代码**上传到 **GitHub 私有仓库**，**不要上传 `.env`**。
2. 打开 [Render](https://dashboard.render.com/) → 新建 **Web Service** → 选择这个 GitHub 仓库。
3. 把 **Build Command** 填成 `npm install`，**Start Command** 填成 `npm start`。
4. 在 Render 的 **Environment** 里填写本机 `.env` 的 7 项：
   `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_APP_TOKEN`、`TEAM_PASSWORD`，以及运行 `setup` 后生成的 3 项 `FEISHU_TABLE_SKU`、`FEISHU_TABLE_BATCH`、`FEISHU_TABLE_SETTINGS`。再加 `NODE_ENV=production`、`FEISHU_REFRESH_MINUTES=20`。
5. 点击部署。成功后 Render 会给你一个 `https://...` 链接。**发这个网址给同事**，不要发 `localhost:3000`。

## 最后：一分钟测试

你在网页点 **英国 → SKU 与库存 → ＋ 新增 SKU**，添加 `TEST-001`，按回车。让同事打开**同一个网址**：通常约 8 秒即可看到。反过来让同事修改库存，你也应该能看到。

### 已经用过旧版？

只要把旧项目的 `.env` 复制到新版文件夹，更新部署即可。**不要再运行 `npm run setup` 或 `npm run seed`**，先备份原来的飞书表格和 JSON。

---

**请保密：** App Secret 和 `.env` 只给管理员使用；同事只需要网站链接和团队登录口令。遇到权限失败，再查看 ZIP 里的《进阶说明_需要排错时再看.md》。
